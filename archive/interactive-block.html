⛓ The Real Problem: Unpriced State Growth

Bitcoin has no mechanism to price the permanent storage cost of data in its UTXO set.
Every unspent output must be kept in RAM by every full node, forever. The cost is distributed across all node operators — not paid by the transaction creator. The fee market only prices block space (supply ~4 MWU per block), not state storage. This is a market failure, and no one has solved it.

✕ What We Tried (And Why It Failed)

v1: Priority Classification Oracle → Dead
Incentive misalignment. Miners won't leave fees on the table. Voluntary classification with no economic penalty collapses to zero signal. The Reddit thread was right: any lying wallet costs nothing.
v2: Externality Fee → Dead
No way to price the "true cost" of a transaction without a market mechanism. Any formula is an arbitrary tax, not a price. The Reddit thread destroyed this pivot too — and they were correct.

📚 What Actually Exists (Surveyed Research)

BIP-141: Segregated Witness (SegWit)
Deployed 2017. Created the weight unit system: block_weight = base_size x 3 + total_size. Witness data costs 1/4 of base data. This is the only differential pricing mechanism Bitcoin has. It was designed to fix malleability, not price state growth. The 4x discount was arbitrary.
Deployed
State Expiry Discussions (No BIP, No Consensus)
UTXO expiry with renewal fees, rent on UTXOs, inactivity pruning — all discussed on bitcoin-dev since ~2020. No proposal has reached BIP status. Contributors: Rusty Russell, Gregory Maxwell, Anthony Towns. Hard questions remain: who reclaims expired UTXOs? What happens to time-locked contracts? How do hardware wallets verify expiry?
Open Research
Covenant Proposals (BIP-119, OP_VAULT, OP_TX, OP_CAT)
Covenants constrain how UTXOs can be spent. BIP-119 (OP_CHECKTEMPLATEVERIFY) enables output-constrained spending. OP_VAULT enables vaults. OP_CAT enables covenant composition. Relevant because covenants can reduce UTXO churn. Key research: "Enhancing Bitcoin Transactions with Covenants" (FC'17).
Draft / Discussion
Layer-2 Absorption (Lightning, etc.)
L2 reduces on-chain state by keeping transactions off-chain. But L2 requires channel factories (more UTXOs), inscriptions bypass L2 entirely, and adoption is insufficient to offset inscription-driven growth. L2 is a mitigation, not a solution.
Active

❓ The Open Research Questions

Q1: How do you price permanent state addition without a market?
In a permissionless system, you cannot charge "rent" — no entity collects it, no way to enforce payment. UTXO expiry has been discussed but raises hard questions about reclaiming, time-locked contracts, and hardware wallet verification.
Q2: Can block weight be refactored to account for UTXO cost?
The SegWit weight formula (base x 3 + witness x 1) was a first attempt at differential pricing. Could we design new_weight = base x w_base + witness x w_witness + new_utxos x w_utxo? But this is still an arbitrary formula — what economic mechanism produces the weights?
Q3: Do we need a second fee market for UTXO creation?
Transactions could pay a fee proportional to new UTXOs created. The fee is burned. The rate adjusts based on UTXO set growth. But this is NOT a price — it's a congestion signal. Who sets the rate? How does it adapt?

🔬 Research Direction (Not a Solution)

Phase R1: Survey Existing Work
Document SegWit discount effects — Survey state expiry discussions — Catalog covenant proposals — Map UTXO growth data
Phase R2: Formalize the Problem
Define the UTXO cost function — Analyze SegWit discount as pricing mechanism — Model inscription externality on node operators
Phase R3: Propose Research Directions
Draft UTXO fee market framing — Evaluate state expiry tradeoffs — Design block weight refactoring — Submit to bitcoin-dev for discussion
Phase R4: Simulation (If Useful)
Simulate UTXO growth under different fee models — Model node operator costs — Publish reproducible results
